Back to Blogging

Oh man do I have a story about my blog. This is not in fact my first blog site. I have made a similar site a few times before. The biggest difference is that the previous site was hosted via GitHub and CloudFlare. The latter of which I have strong feelings about, and you can find that here.

So this is the third time I've created a blog site. The first time I hosted it for free on infinityfree.com. I was happy with their file management system and it was straight forward and easy. Maybe I'm niave, or more likely inexperienced at web development, but I must be the only person who wants to manually create all my sites using html, css, and javascript myself. This is because I want to learn more about web development but I want to do it all myself. I don't want to "vibe code" shit. I don't want to use AI (except in making cheap images for my blog).

What made me move from this platform that I liked, was availability. If I own the domain I can tell people, hey just go to mikerichardson.work. You'll find me. I also was speaking with a friend at work and he asked why I didn't just buy a domain. Upon looking at the prices, I really didn't have an answer. Why not own my own domain?

The problem is that purchasing a domain via CloudFlare was easy and cheap so that enticed me to use them to host as well. My thinking was why wouldn't it be easy use as a host as well? Well, it wasn't! As far as I can tell CloudFlare must have recently made a large change to how their site and hosting sites works. Nearly all the videos I could find on it, referenced a UI that no longer looked or functioned the same way. So hosting my files was basically dead, but if you register a domain with CloudFlare you cannot move it to another domain for 60 days so 1/6th of my domain name lease just sitting and doing nothing.

I then found some other tutorials, still outdated, that showed me how to host the site on GitHub and the connect the page to CloudFlare and I was off to the races...until I wasn't.

Apparently when you make a change to your GitHub page, the repository is rebuilt from the ground up and copies are made, or that is how I understand it anyway. The problem with this method is, at this point in time, I am not interested in learning hwo to be an expert in GitHub. I am learning and trying to build web sites. So between CloudFlare and GitHub being something more than I needed I was and am unable to respond to errors intelligently. Maybe I should learn more about it, but again at this point I'm trying to learn about Web Development add these technologies to it, and I'm getting distracted and sidetracked from my real direct goal.

Now I'm at a point where I own 3 domains. Two are hosted via GitHub and CloudFlare -

  • mikerichardson.work
    •
  • mike-richardson.us
    •
The third I used CloudFlare again to purchase the domain, I checked and they're just the cheapest for domain registration, but the site is hosted with infinity free, and that is this site. I'm still new to it, so we'll see if I fall victim to size restrictions or not, but for the time being I'm happy and the GUI is easy. It's not more than I need, and it's not more complicated than I can navigate with my current understanding.

What Make's This Blog Different

Like I stated this is my third site and thus kind of my third blog. This one is less informal than my last one, or the one before that. I decided that the first two domains can be used professionally and this one is just for me. The whole point of me making my own site is to continue to build and practice my hobbies, like writing, coding, and 3d printing. I think this informality is visible in the navigation bar at the top of the screen. The logo is more fun, and the menu is split into 2. I decided that with this site, I'm less worried about how it looks compared to the rest of the web and of other developers, this is for me.

For now, there are parts that are missing, links, that don't work or go anywhere. That's ok. This is for me, as I learn more, write more, code more, it will begin to fill out. I'm in no hurry. I'm here for the fun of it!
